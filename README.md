# Netflix-Data-Analysis-Dashboard
# 🎬 Netflix Data Analysis

## 📌 About the Project

This project is based on the **Netflix Movies and TV Shows dataset**. The main goal is to explore the data, find useful insights, and present the results using **Python, Pandas, SQL, and Streamlit**.

## 🛠️ Tools & Technologies

* Python
* Pandas
* SQL
* Streamlit
* Exploratory Data Analysis (EDA)

## 🔍 What We Analyzed

### Python & Pandas

We performed data exploration and analysis to understand:

* Total number of Netflix titles
* Movies and TV Shows
* Top countries
* Ratings
* Directors
* Genres
* Release year trends

### SQL

We also used SQL queries to analyze the Netflix dataset and find useful patterns related to content types, countries, ratings, genres, and other aspects of the data.

### Streamlit Dashboard

The analysis was presented through a Streamlit dashboard with charts and visualizations, making the findings easier to understand.

## 📊 Dataset

The dataset contains information about Netflix movies and TV shows, including title, type, director, country, release year, rating, genre, and date added.

## ▶️ How to Run the Dashboard

Install the required libraries:

```bash
pip install pandas streamlit
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Project Objective

The objective of this project is to practice **data analysis, SQL querying, data visualization, and dashboard development** while finding meaningful insights from Netflix data.
